# 青云制作器功能优先级

本文对照剪映、iMovie、InShot、苹果相册回忆，给制作器接下来要做的功能排优先级。P0 的详细设计见 [`dev-0.6.0.md`](./dev-0.6.0.md)。

## 1. 定位与范围

- 定位：自动成片 + 按页轻量编辑。对标苹果相册回忆和剪映的一键成片，不做多轨时间线。
- 平台：只管电脑端（网页版和桌面制作器）。手机端编辑排在 P2。
- 现状：画面部分已经够用（模板、转场、滤镜、拼图版式、取景、视频片段、单页编辑、撤销重做）。差距在声音、防丢失和成片兼容性。

## 2. 优先级总览

| 级别 | 功能 | 版本 |
| --- | --- | --- |
| P0-1 | 配乐与视频原声混音：配乐音量、原声音量、自动压低配乐、单个视频静音 | 0.6.0，包格式 0.4 |
| P0-2 | 转码输出的 H.264 级别过高，旧手机可能解不了 | 0.6.0 |
| P0-3 | 草稿自动保存与恢复 | 0.6.0 |
| P1-1 | 每页说明文字 | 下一版，包格式 0.5 |
| P1-2 | 配乐起点 | 下一版，包格式 0.5 |
| P1-3 | 封面选择 | 下一版 |
| P1-4 | 导出 MP4 边编码边写盘，可选分辨率 | 下一版 |
| P1-5 | 画面比例增加 1:1 和 4:3 | 下一版，包格式 0.5 |
| P2 | 音乐卡点、视频变速、单页滤镜与调色、影片库、贴纸与特效、录音旁白、自动字幕、安卓制作器 | 不排期 |
| 不做 | 多轨时间线 | |

## 3. P0 为什么排在最前

- **混音**：主流剪辑软件里配乐和原声都是同时存在、各自可调的。现在选了配乐，视频原声就整个没了，生日歌、孩子说话这类声音留不下来。这是和同类产品差距最大的一处。
- **H.264 级别**：转码出来的视频在旧手机上可能放不出来，做出来的影片对方打不开，比少一个功能严重。
- **草稿**：现在关掉页面或程序崩溃，没保存的编辑全部丢失。素材越多，损失越大。

## 4. 已确认的决定

- 混音升包格式 0.4。旧播放器（v0.5.1 及更早）打开 0.4 的包提示版本不支持；新播放器照常打开 0.1 到 0.3 的包。
- 新建影片默认开原声：视频页原声 100%，配乐在有声视频页压到 30%。重新打开的旧影片保持原来的静音。
- 压低比例固定 30%，过渡固定 0.5 秒，界面只给开关。
- 草稿只保留一份（当前正在编辑的那部）。
- 每页文字在播放器、预览、MP4 三处都显示；片头标题维持现状（播放器不显示，预览和 MP4 显示）。

## 5. P1：需求、规则、验收

格式改动（P1-1、P1-2、P1-5）合并成一次升级 0.5，同一个版本发布。

### P1-1 每页说明文字

- 需求：每页可以填一段文字，最多 40 个字，显示在画面下方居中，页开始后淡入、页结束前淡出。
- 规则：做法与片头标题相同，制作器把文字画成与画布同尺寸的透明 PNG 放进包里，清单里每页记录图片和淡入淡出时间。图层角色用 `caption`，播放器、预览、MP4 都画。播放器去掉标题层的逻辑只针对 `title`，不影响它。
- 验收：同一部影片在播放器、预览、MP4 三处，同一页的文字位置和出现时间一致；文字留空的页不生成图片；重新打开后文字可以继续改。

### P1-2 配乐起点

- 需求：可以让配乐从曲子的第 N 秒开始，方便跳过前奏。
- 规则：清单加 `bgm.start`（秒，缺省 0）。配乐位置 = `start + 影片时间`，循环时对曲长取模。界面是一个滑块加试听按钮。
- 验收：起点设为 20 秒，预览、播放器、MP4 的第一声都是曲子的第 20 秒；旧包行为不变。

### P1-3 封面选择

- 现状：封面固定是第一页第一个素材（`apps/web/src/create/cover.ts`）。
- 需求：在页面条上可以把任意一页设为封面。
- 规则：封面取该页播放到一半时的整页画面（含拼图版式和滤镜，不含片头标题），最长边 640。选择记在 `generator` 的私有数据里，不改包格式。
- 验收：把第 3 页设为封面，保存后播放器首页和系统文件预览显示的是第 3 页；重新打开后仍是第 3 页；该页被删除后回到默认。

### P1-4 导出 MP4 边编码边写盘，可选分辨率

- 现状：整部 MP4 先放在内存里，超过 10 分钟要先提示。
- 需求：导出前先选保存位置，编码的同时写文件；可选 1080p 或 720p。
- 规则：网页版用文件系统访问接口（Chrome、Edge 支持），桌面制作器用 Tauri 的文件写入；都不可用时退回现在的内存方式并保留长片提示。720p 的码率为 4 Mbps。
- 验收：导出 15 分钟的影片，页面内存占用不随进度持续上涨；中途取消后不留下半截文件；720p 的输出尺寸为 1280×720 或 720×1280。

### P1-5 画面比例增加 1:1 和 4:3

- 需求：画面比例多两个选项。
- 规则：画布尺寸 1080×1080 和 1440×1080；2 到 4 张的版式在这两个比例下都沿用 16:9 的排法；MP4 导出按画布尺寸输出。清单的 `aspectRatio` 增加两个取值。
- 验收：四种比例下各版式的格子都不重叠、不出画布；播放器在横竖屏下画面居中不变形；MP4 的尺寸与画布一致。

## 6. P2：条目和理由

| 功能 | 排后的理由 |
| --- | --- |
| 音乐卡点 | 需要节拍检测，且页时长现在由配乐长度反推，改动面大 |
| 视频变速 | 涉及原声变调和导出重采样，回忆影片里用得少 |
| 单页滤镜与调色 | 整片滤镜已经覆盖主要场景 |
| 影片库 | PRD 里的 F-LIB，依赖草稿和文件管理，等草稿落地后再评估 |
| 贴纸与特效 | 与“回忆影片”的定位关系弱 |
| 录音旁白 | 需要录音权限和第三路混音，等混音稳定后再做 |
| 自动字幕 | 需要语音识别，本地模型体积大 |
| 安卓制作器 | 手机端编辑整体排后 |
