# 制作器：选完素材之后的预览、返回和保存

本文是制作器预览布局和保存入口的开发依据。只改这里写明的行为，不加别的交互。

## 1. 现象和原因

选完照片或视频后，预览把整个窗口盖住。顶栏菜单和左侧素材栏点不到，所以看不到「保存」，也回不到素材列表。画面右下角浮着「移到下一页」「后移本页」「与下一页合并」。

这些字是右侧「本页」面板里的按钮，定义在 [`apps/web/src/create/PagePanel.tsx`](../apps/web/src/create/PagePanel.tsx)。它们不该出现在影片画面上。

制作器预览直接用了播放器组件 [`apps/web/src/PlayerView.tsx`](../apps/web/src/PlayerView.tsx)。它的根节点是 `position: fixed`，四个边都是 0，按整窗播放器来铺。放进预览区后仍然盖住整个窗口。右侧面板在 DOM 里排在播放器后面，又没有自己的底色，所以只有这几个按钮浮在画面上。

独立播放器（打开 `.qyp` 的那个窗口）保持全屏固定定位，不改。

## 2. 预览只占中间一栏

`PlayerView` 增加属性 `embedded`，缺省为假。

- `embedded` 为假：根节点仍是 `position: fixed`，四个边为 0。独立播放器不传这个属性。
- `embedded` 为真：根节点改为 `position: absolute`，`top`、`right`、`bottom`、`left` 都是 0，只铺满预览舞台，不相对窗口。

[`apps/web/src/create/PreviewPane.tsx`](../apps/web/src/create/PreviewPane.tsx) 的舞台（现在的 `stage`）设为 `position: relative` 和 `overflow: hidden`，创建 `PlayerView` 时传入 `embedded`。

[`apps/web/src/create/CreatorApp.tsx`](../apps/web/src/create/CreatorApp.tsx) 里左栏、右栏的背景用 `theme.bg`，不透出影片。顶栏（菜单和下面第 3 节的保存按钮）画在播放器之上，可以点。

窗口宽度小于 1000px（[`DESKTOP_MIN_WIDTH`](../apps/web/src/create/editor/layout.ts)）时仍是「素材 / 预览 / 设置」三个标签。预览标签里的播放器同样传 `embedded`，不盖住底栏标签。

验收：

- 加一张横图后，左侧素材列表、顶栏、右侧「影片 | 本页」都看得到、点得到。
- 画面上不再出现「移到下一页」「后移本页」「与下一页合并」。这些字只在右侧「本页」面板里。
- 打开一部 `.qyp` 进入独立播放器，画面仍铺满窗口。

## 3. 保存始终看得见

有至少一个素材时，顶栏右侧放一个主按钮，文案是「保存」。没有素材时不显示这个按钮。正在保存、打开或导出时禁用。

点击这个按钮等同菜单「文件 → 保存…」，快捷键仍是 Ctrl+S（Mac 上是 ⌘S），处理函数不另写一套：

- 桌面制作器弹出系统保存框。
- 网页版下载 `.qyp`。
- 配乐是用户导入的音乐时，保存前仍先确认使用权。内置曲目不提示。

桌面制作器不显示「回到播放器」。`isDesktop()` 为真时现在就是这样，保持不变。网页版制作器保留顶栏已有的「回到播放器」。

保存成功后的提示仍用现在的「已保存 {name}」，不另做一条。

验收：加一张图之后，不用打开菜单就能点到「保存」。保存成功后出现现有的已保存提示。没有素材时顶栏没有「保存」。

## 4. 选完素材之后的去向

宽窗口（宽度不小于 1000px）：

- 导入成功后不切换任何标签，右栏停在「影片」，不自动切到「本页」。
- 左栏是刚加入的素材，中间自动开始预览。

窄窗口（宽度小于 1000px）：

- 这一批文件里至少成功加入一个素材时，导入结束后切到「预览」标签。
- 预览状态行右侧放两个按钮：「素材」和「保存」。
- 「素材」把当前标签设回「素材」。
- 「保存」与第 3 节顶栏「保存」是同一次点击处理，包括禁用条件和导入音乐的使用权确认。窄窗口顶栏如果放不下，可以只在预览状态行放「保存」，但两处不能各写一套保存逻辑。
- 底栏「素材 / 预览 / 设置」三个标签保持可点。

导入失败的文件仍只出现在素材栏的失败列表。这一批如果一个都没加入成功，不切换标签。

点页面条上的某一页：仍选中该页，预览跳到该页，右栏切到「本页」。窄窗口则切到「设置」标签里的「本页」。这是现在 `selectPage` 的行为，保留。

验收：

- 窄窗口一次选 3 张照片和 1 段视频，松手后看到预览，点「素材」回到素材列表，点「保存」开始保存。
- 宽窗口三栏同时在，保存按钮在顶栏，右栏仍是「影片」。
- 只选一个损坏文件时，仍停在原来的标签，失败原因在素材栏。

## 5. 不改的部分

单页操作仍只在「本页」面板：移到上一页、移到下一页、前移本页、后移本页、与下一页合并、删除本页、取景、视频片段。不做到画面上，不做成长按菜单。

`CreatorApp` 超过 300 行是既有警告，不因此拆文件。
