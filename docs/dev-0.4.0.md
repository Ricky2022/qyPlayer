# 青云播放器 0.4.0 开发说明

0.4.0 参照苹果“照片”里的回忆影片，优化画面观感和播放体验。本文档是开发依据；0.3.0 保持预览版，不出正式版，原 0.3.0 的 S8（CSP、`Cargo.lock`、许可同步、真机验收、发布）并入本版最后一步。

## 1. 已确认的决定

| 编号 | 决定 |
| --- | --- |
| E-01 | 版本做成 0.4.0，在 `release/0.4.0` 分支上开发；发布前只推该分支，不动 `main`。 |
| E-02 | 清单格式升到 **0.3**。0.4.0 能读 0.1、0.2、0.3；0.3.0 预览版打开 0.3 的包时提示“不支持的格式版本”。 |
| E-03 | 背景只做一种：留空处用当前素材放大后重度模糊并压暗的画面。不做纯色自选、自选图片、内置纹理。 |
| E-04 | 拼图改成卡片式：整组四周留外边距、格子间隙加大，直角。 |
| E-05 | Ken Burns（缓慢推拉平移）只用于单张照片页；拼图页和视频页不加。 |
| E-06 | 片头标题卡：制作时把标题和副标题画成与画布同尺寸的透明 PNG 存进包，播放器只贴图。副标题缺省为空，填了才显示。 |
| E-07 | 时长分短、中、长三档：长用全部素材，中约 60%，短约 30%；先去掉拍摄时间挨得最近的素材。 |
| E-08 | 整片滤镜 5 款：原片、黑白、暖色、冷色、怀旧。 |
| E-09 | 转场可单独选择（跟随模板、淡入淡出、滑动、缩放、旋转），新增“旋转”。 |
| E-10 | 播放器增加上一页、下一页和底部缩略图条；不做网格总览。 |

苹果文档里没有写明、但这类影片常见的 Ken Burns，来自 iMovie 文档和第三方文章，不是苹果回忆文档的内容。

## 2. 清单格式 0.3

只增加可选字段。`formatVersion` 为 `"0.3"` 时，素材仍必须带 `mimeType` 和 `source`（同 0.2）。播放器必须忽略不认识的字段和取值，缺字段时的行为与 0.2 完全一致。

| 位置 | 字段 | 说明 |
| --- | --- | --- |
| `canvas` | `backdrop` | `"blur"`：留空处画模糊背景。缺省或不认识的值：只用 `canvas.background`。 |
| `pages[].items[]` | `motion` | `{ from: {scale, x, y}, to: {scale, x, y} }`，在整页时长内匀速变化。`scale` 相对于素材按 `fit` 放好后的大小；`x`、`y` 以格子宽、高为单位。 |
| `pages[].transitionIn` | `type` | 新增取值 `"rotate"`。不认识的类型仍按 `fade` 处理。 |
| 顶层 | `look` | `"mono"`、`"warm"`、`"cool"`、`"vintage"`；缺省或不认识的值按原片。 |
| 顶层 | `subtitle` | 副标题文字，只用于还原编辑设置和显示信息。 |
| 顶层 | `titleCard` | `{ assetId, start, duration, fadeIn, fadeOut }`，`assetId` 指向素材表里一张与画布同尺寸的透明 PNG。没有这个字段就不显示标题。 |
| `generator` | `transition` | 用户选的转场，用于重新打开时还原；缺省表示跟随模板。 |

校验：

- JSON Schema：新增上述字段的结构；`formatVersion` 为 `"0.2"` 或 `"0.3"` 时素材必须带 `mimeType` 和 `source`。
- 语义：`motion` 的 `scale` 必须大于 0；`titleCard.assetId` 必须引用图片素材，`start`、`duration` 不得使标题超出影片时长。
- `formatVersion` 为 `"0.4"` 仍是 `unsupported-version`。

## 3. 每帧的绘制顺序

画布背景色 → 每页的模糊背景层 → 素材层（含 Ken Burns、入场、转场、旋转）→ 整片滤镜叠色 → 标题图片层。

`stateAt`（`packages/core`）算出这些层，`renderFrame`（`packages/renderer`）只管画；预览、播放、导出 MP4 共用这两处，三者画面一致。

- `Layer` 新增 `role?: "backdrop" | "title"` 和 `rotation?`（弧度，绕画布中心）。
- 只有一页里有多于一个素材、或有 `fit` 为 `contain` 的素材时才生成背景层，取该页第一个素材，铺满画面，跟随整页的转场变换。
- 背景层的模糊：先把素材缩到很小的离屏画布，再两级放大回去，最后盖一层半透明黑。不用 `ctx.filter`（Safari 默认不支持）。静态图片的小图缓存，视频每帧重算。
- 滤镜用 `globalCompositeOperation` 的混合模式叠色，不读写像素。

## 4. 各项细节

### 4.1 背景与卡片式拼图
`layoutFrames` 的 2 到 4 张版式：外边距为画布短边的 4%，格子间隙 2%；单张仍铺满。旧包的格子写在清单里，不受影响。导出时 `videoLayers` 要排除背景层，避免同一段视频的时间点重复。

### 4.2 Ken Burns
生成器为每个单张照片页写入 `motion`，随机选：推近、拉远、保持放大并沿四个方向之一平移。`fit` 为 `cover` 时 `scale` 取 1.00 到 1.08，偏移不超过 `(scale-1)/2`，保证始终盖满格子；`fit` 为 `contain` 时只在 0.94 到 1.00 之间缩放。随机数用独立的种子流，不改变转场和版式的选择结果。

### 4.3 转场
旋转：新页从 6 度、放大 1.15 倍转正并淡入，上一页转出 6 度、放大到 1.15 倍并淡出。用户指定转场时，首页仍是淡入，其余页全部用所选类型；滑动的方向仍随机。三个模板的权重不变，“旋转”只在用户明确选择时出现。

### 4.4 滤镜
5 款：原片（不处理）、黑白（`saturation` 混合中灰）、暖色、冷色（`overlay` 叠 #ff9a3c、#3c8cff，不透明度 0.3）、怀旧（`saturation` 0.35 半去色、`multiply` #f2dcb0 0.45 叠暖黄、`lighten` #1e1a16 抬黑位）。数值在 `packages/renderer/src/looks.ts`，用 `playground.html?m=looks` 出对比图，经用户确认后定稿。

### 4.5 片头标题卡
标题和副标题画在透明 PNG 上（底部压暗渐变加文字，标题最多两行，字号为短边的 6%，副标题 3.5%）。标题在 0.3 秒淡入，到第 3 秒淡出（淡入淡出各 0.5 秒；第一页不足 3 秒则在该页结束前淡出）。标题层在滤镜之后，不受整页转场影响。还原编辑时只取页里出现过的素材，标题图片不会被当成用户素材。字体取制作时那台电脑的字体。

### 4.6 时长三档
`selectByLength(media, length)`：目标数量为 `ceil(n × 比例)`（中 0.6、短 0.3），素材少于 10 个时只有“长”。反复去掉“相邻两项都有拍摄时间且间隔最小”的一对里靠后的那个；没有这样的一对时，按顺序均匀抽取并保留首尾。未入选的素材不进包，素材面板里变灰并标注。`length` 不写进清单，重新打开一律是“长”。

### 4.7 播放器
上一页、下一页按钮（PageUp、PageDown）和底部缩略图条；缩略图条默认不显示，控制条右侧有开关，选择存在 localStorage 的 `qy.filmstrip`（`"on"` 或 `"off"`）。跳转目标是该页转场结束的时刻。缩略图只为可见范围内的页生成，一次一个，用与播放相同的渲染函数画在小画布上。制作器内嵌预览里不显示缩略图条。

## 5. 暂定数值

| 项 | 值 |
| --- | --- |
| 拼图外边距 / 间隙 | 画布短边的 4% / 2% |
| 模糊背景上的黑色不透明度 | 35% |
| Ken Burns | cover：1.00 到 1.08；contain：0.94 到 1.00 |
| 标题 | 0.3 秒淡入，第 3 秒淡出，淡入淡出各 0.5 秒 |
| 时长比例 | 中 60%，短 30%，向上取整；少于 10 个素材只有“长” |
| 旋转转场 | 6 度，放大到 1.15 倍 |

## 7. 需要用户参与

- 滤镜数值：出对比图，用户确认。
- iPhone Safari：混合模式和模糊背景在这台电脑上验证不了，需要用户用手机打开网页播放器看一遍；某款滤镜在 iPhone 上不对，就换一种叠色办法。
- N9 的真机验收和 Windows Media Player 检查，同原 S8。

## 8. 风险

- 时长三档按规则抽取，不识别画面内容，可能抽掉用户想留的照片。
- Ken Burns 以画面中心为准，不识别人脸，靠边的人脸可能被裁到（与现在的居中裁切相同）。
- 标题字体取制作时那台电脑的字体，不同电脑制作出来的字形不同；同一个包在各设备上播放一致。
- 0.3.0 预览版打不开 0.3 格式的包，需要升级到 0.4.0。
