# 青云播放器 0.4.1 开发说明

0.4.1 给制作器加上**单页编辑**，并带上已完成的“播放器缩略图条改为可选（默认不显示）”。清单格式仍是 0.3，不新增播放器要理解的字段；0.4.0 的播放器能照常打开 0.4.1 做的包。

## 1. 已确认的决定

| 编号 | 决定 |
| --- | --- |
| F-01 | 版本 0.4.1，在 `release/0.4.1` 分支上开发（从 `feature/optional-filmstrip` 切出）；发布前只推该分支，经用户确认后才合并 `main` 并打标签。 |
| F-02 | 单页编辑包含：每页的时长、转场、版式（含页内顺序）、显示方式（自动、铺满、完整显示）；页的前移、后移、删除、照片移到相邻页、单独成页、与相邻页合并；照片取景（平移、缩放、Ken Burns）；视频片段的起点和长度。 |
| F-03 | 不做：视频页静音、每页文字说明、入场动画的单独编辑、首页转场（首页固定淡入）。 |
| F-04 | 做过单页修改后，增删素材只动相关的页；换模板、换一版、改时长档、按拍摄时间排序、素材列表里拖动排序会整片重排，有单页修改时先确认，可撤销。 |
| F-05 | 清单格式不变（0.3）。手动编排写进 `generator.plan`（生成器的私有数据，播放器不读）。 |

## 2. 自动编排与手动编排

编辑状态 `EditorDoc.pages` 为 `null` 表示**自动编排**，行为与 0.4.0 完全一样（素材 + 设置 + 种子 → 整部影片）。第一次做单页修改时，把当前自动编排的结果原样存进 `pages`（画面不变）再应用这次修改，此后是**手动编排**。

生成器拆成两段，自动模式下的输出与 0.4.0 完全相同：

- `planPages(options)`：所有“挑选”（分页、格子匹配、转场、入场、Ken Burns 种类），产出 `PagePlan[]`。随机数的消耗顺序与 0.4.0 一致。
- 组装（`generateManifest` 里 `planPages` 之后的部分）：节奏缩放、起止时间、转场时长、版式取格子、取景换算、素材表、配乐、片头标题。
- `generateManifest(options)`：`options.pages` 缺省时先 `planPages`，给了就直接用；两者的结果相同（有测试）。

```ts
interface ItemPlan {
  assetId: string;
  fit?: "cover" | "contain";                 // 缺省：按裁切损失自动
  crop?: { zoom: number; x: number; y: number }; // 取景，见第 4 节
  kenBurns?: "none" | "in" | "out" | "left" | "right" | "up" | "down"; // 缺省：自动（单张照片页随机）
  clipStart?: number;                        // 仅视频；缺省居中截取
  enter?: Enter;
}
interface PagePlan {
  items: ItemPlan[];                         // 顺序即格子顺序
  layout?: string;                           // 缺省：该张数的默认版式
  transition?: { type: string; direction?: string };
  duration?: number;                         // 秒；缺省自动
}
```

校验（`GenerateError("invalid-plan")`）：每个素材恰好出现一次；每页 1 到 4 个；视频独占一页；`crop.zoom` 在 1 到 3；`duration` 大于 0。

### 2.1 节奏

- 视频页：时长 = 片段长度。片段长度取 `plan.duration`（不超过素材时长）；缺省为 `min(素材时长, 8 秒)`。`clipStart` 缺省居中，指定时夹在 `[0, 素材时长 - 片段长度]`。
- 照片页：`plan.duration` 指定的算固定时长；其余照片页按配乐缩放（0.7 到 1.6 倍），缩放时扣除视频页和固定时长页。

### 2.2 手动编排下的整片操作

| 操作 | 规则 |
| --- | --- |
| 添加素材 | 新素材按模板规则分页，接在末尾；已有页不动 |
| 删除素材 | 从所在页去掉，空页删除；页内素材少了则版式换回该张数的默认版式，其余设置保留 |
| 改画面比例、换配乐、改滤镜、标题、副标题、标题开关 | 保留所有页 |
| 全片转场 | 非“跟随风格模板”时覆盖第 2 页起所有页的转场；选“跟随风格模板”不改各页已有的转场 |
| 换模板、换一版、改时长档、按拍摄时间排序、素材列表拖动排序 | 整片重排：先确认，确认后 `pages` 回到 `null` |
| 恢复自动编排（新命令） | 先确认，`pages` 回到 `null` |

手动编排时素材列表的顺序跟随页的顺序（页内按格子顺序）。

## 3. 版式

版式按“张数 + 编号”取格子，格子的外边距（4%）和间隙（2%）规则同 0.4.0。大格子永远是第 1 张。

| 张数 | 编号（默认值：横屏 / 竖屏） | 说明 |
| --- | --- | --- |
| 1 | `full` | 铺满 |
| 2 | `side`（横屏默认）、`stack`（竖屏默认） | 左右、上下 |
| 3 | `big-left`（横屏默认）、`big-right`、`big-top`（竖屏默认）、`big-bottom` | 第 1 张是大格子，另外两张占另一半 |
| 4 | `grid`（默认）、`big-left`、`big-top` | 田字；或第 1 张大格子，另外三张排成一列、一行 |

编号对该张数无效时用默认版式。默认版式与 0.4.0 的格子完全相同。

## 4. 取景与 Ken Burns

取景 `crop = { zoom, x, y }`：`zoom` 是相对“铺满”的放大倍数（1 到 3），`(x, y)` 是可见区域中心在素材上的位置（0 到 1，素材坐标，与版式、比例无关）。

设格子宽高比 A，素材宽高比 a，`R = max(a/A, A/a)`。放大倍数 `z` 时，可见区域占素材的比例：

- a > A：`vw = 1/(R·z)`，`vh = 1/z`
- a ≤ A：`vw = 1/z`，`vh = 1/(R·z)`

中心夹到 `[vw/2, 1-vw/2]`、`[vh/2, 1-vh/2]` 内。输出到清单时用 `fit: "contain"` 加 `motion`：

- 缩放 `S = R·z`。素材在格子里按完整显示的大小再乘 `S`，显示尺寸（格子宽高为单位）为 `dispW = (a>A ? 1 : a/A)·S`，`dispH = (a>A ? A/a : 1)·S`。
- 偏移 `x = -(cx-0.5)·dispW`，`y = -(cy-0.5)·dispH`。夹取后恒有 `|x| ≤ (dispW-1)/2`、`|y| ≤ (dispH-1)/2`，格子始终被盖满。

Ken Burns 种类（`kenBurns`）：

- 没有取景时，沿用 0.4.0 的数值：cover 的 `in`（1.00 到 1.08）、`out`、四个方向（1.08 倍，偏移 ±0.035 格）；contain 只有 `in`、`out`（0.94 到 1.00），方向类按 `none` 处理；`none` 不写 `motion`。
- 有取景时，Ken Burns 作用在取景的可见区域上：`in`：`z` 到 `z·1.08`；`out`：反过来；方向类：`z·1.08`，中心沿方向移动 `±0.035·vw`（或 `vh`），再夹取。
- 仅单张照片页提供；视频页和拼图页没有 Ken Burns，缺省 `none`。

## 5. 暂定数值

| 项 | 值 |
| --- | --- |
| 页时长 | 自动，或 1 到 15 秒，步长 0.5 秒 |
| 视频片段长度 | 1 秒到素材时长，上限 60 秒 |
| 取景放大倍数 | 1 到 3；方向键平移步长为可见区域的 5% |
| 滑块连续拖动合并为一步撤销 | 间隔不超过 1 秒 |
| 预览去抖 | 沿用 300 毫秒 |

## 6. 编辑状态与保存

- `EditorDoc.pages` 的页内素材用 `EditorMedia.key` 标识（清单里的素材 id 是按位置编的，增删素材会变）；生成清单时按 `selectedMedia` 的顺序映射成 `m001…`。
- 手动编排时 `generator.plan` 写 `PagePlan[]`（素材用清单里的 id）；自动编排不写。
- 还原：`generator.plan` 合法（通过上述校验、素材 id 都存在）就进入手动编排，否则按自动编排打开并沿用“排版可能不同”提示。
- 保存时转码把视频裁成片段，`clipStart` 改为 0，`generator.plan` 同步。

## 7. 界面

- 预览下方的页面条：每页一张缩略图（复用播放器的缩略图渲染），带页码和时长；点击选中并让预览跳到该页；桌面上可拖动排序，Alt + 左右键移动页，Delete 删除页。
- 右侧面板顶部“影片 | 本页”切换；选中页后自动切到“本页”，按页的类型（单张、拼图、视频）只显示适用的控件。
- 预览重新生成后停留在选中的页。
- 手机：页面条在“预览”标签，“本页”在“设置”标签，条旁有“编辑本页”按钮；排序用前移、后移按钮。

## 9. 验收

- 单元测试：编排拆分前后结果相等；每个页操作；整片操作的保留与重排；取景换算（盖满、边界夹取）；还原与转码补丁。
- Chrome：逐项操作一遍，保存后重新打开继续编辑，导出 MP4 抽帧核对；用 0.4.0 的播放器打开 0.4.1 做的包，画面一致。
- CI：手动运行 Release 工作流，`--locked` 构建通过，桌面制作器实机看一遍。
- iPhone Safari、Windows 媒体播放器：同 0.4.0，由用户验收。

## 10. 风险

- 每次单页修改都会重建预览和缩略图，页多时可能有延迟；先沿用去抖，实测不行再只重画受影响的页。
- 取景对话框依赖浏览器能解码该照片；解不了的（未转码的 HEIC）禁用取景并提示。
- 手机上不做拖动排序，只用按钮。
- 有取景的照片输出为 `contain`，页里会多一层模糊背景（被完全盖住，只是多花一点计算）。
