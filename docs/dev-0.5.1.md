# 青云播放器 0.5.1 开发说明

0.5.1 是一次小改版：修掉 Android 上播放界面黑屏的问题，并把「竖屏看横屏影片」的观感做成 Apple 影集那种样子。包格式、桌面版功能都没有变化。

## 1. 黑屏的原因与修法

真机（Android 11、系统 WebView 是 **Chrome 83**）上播放界面全黑。用 `adb` 连上 WebView 的 DevTools 之后可以直接读到：

- `document.querySelector('#root > div').getBoundingClientRect()` 是 **0×0**
- 播放器舞台和画布也都是 0×0

原因是播放界面用了三个 Chrome 83 不支持的 CSS：

| 特性 | 需要的最低版本 | 用在哪 |
| --- | --- | --- |
| `inset` 简写 | Chrome 87 | 播放器根节点、舞台、关于对话框、拖放提示 |
| `aspect-ratio` | Chrome 88 | 画布按影片比例缩放、取景对话框 |
| flex `gap` | Chrome 84 | 播放器控制行、首页按钮、页面条 |

改成：四个边写全（`top/right/bottom/left`）、画布尺寸由脚本按舞台可用空间和影片比例算出来、需要间距的地方用相邻外边距；取景对话框在制作器里（桌面），暂不处理。

## 2. 竖屏观感

- 舞台铺一层「环境背景」：把当前画面每隔约 80 毫秒缩到 160×90 的小画布上，再用 CSS 模糊（28px）、压暗（0.45）、略微放大铺满。竖屏看横屏影片时，四周是画面的柔和延伸，不再是死黑。
- 影片画面本身变成一张卡片：8px 圆角 + 柔和投影，接近 Apple 影集的观感。
- 横屏或全屏、画面已经铺满时，背景层被画面完全挡住，看不出差别。

## 3. 播放时不叠片头标题

片头标题是制作时画进包里的透明图，文字在第一页左下角（这两部影片是「2026-01-17 回忆」），大约从 0.3 秒显示到第 3 秒。播放器不再画这一层。制作器里勾选「显示标题」时，预览和导出的 MP4 仍会带上。

## 4. 安卓上视频原声没了

这两部影片没有背景音乐。前 7 页是照片，本来就没有声音。唯一的声音在最后一页：`media/m009.mp4` 里有一条 AAC 音轨（约 8 秒、约 117 kbps），不是空轨。

安卓 WebView 默认要求一次点击才允许出声。用户一点播放，视频要过二十多秒才出现，这次点击已经过期，`play()` 被拒绝。画面靠不断定位还能往前走，所以看起来在播，但没有声音。另外，不在页面上的 `video` 元素、以及音量先写成 0 再播放，这台 WebView 也会把音轨丢掉。

改动：壳里关掉 `mediaPlaybackRequiresUserGesture`；视频和背景音乐挂进文档（1 像素、几乎透明）；点播放时在同一次点击里就调用 `play()`；刚开始播时音量不写成 0。

## 5. 兼容性备注

- `boot-guard.js` 继续保留：主脚本加载失败时它会把原因和浏览器 UA 画在屏幕上。
- 构建目标保持 `chrome80 / edge80 / firefox78 / safari14`。
- 0.5.1 起，手机端的最低要求写为：Android 10 及以上 + 系统的 Android System WebView 80 及以上（一般随商店更新）。

## 6. 版本

版本号 0.5.1（8 处加 `Cargo.lock` 里三个工作区 crate），README、发布说明同步；APK 命名 `qyPlayer-0.5.1-android-arm64.apk`。
